# App 技能广场建设 & 双端小智技能能力对齐 · PRD v1.0

百智 WiseNote 需求文档与高保真原型（静态站点，GitHub Pages 托管）。

## 内容

| 页面 | 说明 |
| --- | --- |
| `index.html` | 目录页 |
| `prd.html` | 需求文档 PRD v1.0（10 章，含 9 张原型截图） |
| `app-prototype.html` | App 端原型：技能广场、添加技能浮窗、技能详情、问问助手 |

## 本期边界

- 只支持从技能广场**添加 / 卸载平台公开技能**，不做个人技能创建与上传。
- 广场只做添加与卸载，启用动作收口到会话与详情。
- 添加上限 15、启用上限 3，双端同源、服务端校验。

> 页面为高保真静态原型，数据均为演示数据。
